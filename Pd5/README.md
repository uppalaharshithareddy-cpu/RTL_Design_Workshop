🛣️ PD 5 – Routing

🎯 Objective

To understand routing and learn how electrical connections are created between standard cells in a physical design.

📚 Topics Covered

- Global Routing
- Detailed Routing
- Metal Layers
- Vias
- Routing Congestion
- Parasitic Extraction
- Design Rule Checking (DRC)
- Post-Route Timing Analysis

🛠️ Tools Used

- OpenLANE
- OpenROAD
- Magic
- OpenSTA
- SKY130 PDK

🔄 Implementation Steps

1. Load the design after placement and CTS.
2. Perform global routing.
3. Perform detailed routing.
4. Examine the routed layout.
5. Check connectivity.
6. Analyze routing reports.
7. Review post-route timing.
8. Examine physical verification results.

💻 Command

In a compatible OpenLANE interactive flow:

"run_routing"

💡 Key Learnings

- Understood the difference between global and detailed routing.
- Learned how metal layers and vias connect circuit components.
- Understood routing congestion.
- Learned the importance of parasitic extraction.
- Understood the purpose of physical verification.

✅ Conclusion

Routing creates the physical electrical connections between circuit components. Post-route analysis helps evaluate timing and physical design quality.
