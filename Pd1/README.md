🔰 PD 1 – Introduction to Physical Design

🎯 Objective

To understand the basic concepts of ASIC Physical Design and learn how a synthesized RTL design is converted into a physical layout.

📚 Topics Covered

- Introduction to Physical Design
- ASIC Design Flow
- RTL Design and Synthesis
- Standard Cell Libraries
- Introduction to OpenLANE
- SKY130 PDK

🛠️ Tools Used

- OpenLANE
- Yosys
- SKY130 PDK
- OpenROAD
- OpenSTA

🔄 Physical Design Flow

1. RTL Design
2. Synthesis
3. Floorplanning
4. Placement
5. Clock Tree Synthesis (CTS)
6. Routing
7. Physical Verification

💡 Key Learnings

- Understood the ASIC design flow.
- Learned the purpose of synthesis.
- Understood the role of standard-cell libraries.
- Learned how physical design stages work together.
