### Smart Street Light Controller

## Project Overview

The Smart Street Light Controller is a digital design project implemented using Verilog HDL. It controls street light modes based on the surrounding lighting condition and vehicle detection.

The design uses a Finite State Machine (FSM) to select the appropriate lighting mode.

## Features

- Day mode when it is daytime.
- Night mode when it is dark and no vehicle is detected.
- Bright mode when a vehicle is detected at night.
- Synchronous state transitions controlled by a clock.
- Active-high asynchronous reset.
- Verilog testbench for functional verification.

## Light Modes

Mode| Encoding| Description
DAY| "2'b00"| Street light is in day mode
NIGHT| "2'b01"| Street light is in night mode
BRIGHT| "2'b10"| Bright lighting when a vehicle is detected

## Tools Used

- Verilog HDL
- Icarus Verilog for simulation
- GTKWave for waveform viewing (optional)
- Yosys for logic synthesis

## Simulation

Compile the RTL and testbench using Icarus Verilog:

iverilog -o smart_street_light_sim rtl/smart_street_light.v testbench/tb_smart_street_light.v

## Run the simulation:

vvp smart_street_light_sim

If the testbench generates a VCD waveform file, open it with GTKWave:

gtkwave dump.vcd

Use the actual VCD filename generated by your testbench if it differs from "dump.vcd".

## Synthesis

Yosys can be used to synthesize the Verilog design and inspect the resulting logic.

## Project Goal

To demonstrate FSM-based digital design, Verilog coding, functional simulation, and logic synthesis for an intelligent street-lighting system.
