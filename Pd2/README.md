🏗️ PD 2 – Floorplanning

🎯 Objective

To understand floorplanning and learn how the initial physical structure of a chip is created.

📚 Topics Covered

- Die Area and Core Area
- Core Utilization
- Aspect Ratio
- Pin Placement
- Placement Rows
- Tap Cells and Endcap Cells
- Power Planning

🛠️ Tools Used

- OpenLANE
- OpenROAD
- SKY130 PDK

🔄 Implementation Steps

1. Load the design.
2. Configure floorplanning parameters.
3. Define the core and die dimensions.
4. Place input and output pins.
5. Create placement rows.
6. Generate the power distribution network.
7. Examine the floorplan.

💡 Key Learnings

- Understood the difference between core area and die area.
- Learned how utilization affects available placement space.
- Understood pin placement.
- Learned the purpose of power planning.
