# Module 3

## RTL Design Workshop

### Objective

The objective of this module is to understand RTL design concepts and their implementation using Verilog HDL.

### Topics Covered

- RTL design fundamentals
- Verilog HDL
- Combinational logic
- Sequential logic
- Simulation and verification

### Learning Outcome

After completing this module, I gained an understanding of RTL design methodology and Verilog-based digital circuit implementation.
